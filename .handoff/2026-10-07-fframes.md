## Skill test

A fresh general-purpose subagent got only the idea "A seed becomes a tree, about 10 seconds" and the skill path. It produced `out/seed-tree/seed-tree.mp4`: 11.23 s, 1920x1080 at 30 fps, 337 frames, with audio. `inspect` was clean, and the mix measured -15.6 LUFS with a -1.5 dBTP peak. The strip is at `out/seed-tree/strip.png`. The first build took 1 min 32 s, rebuilds 6 to 9 s, and the render 13 s. The compiler and the tools raised no errors.

It reported eleven gaps in the skill. These were fixed in the skill and in `npm run fframes-sync`:

- the main-checkout rule;
- the `multi-scene` template;
- the template's `--title` flag and `tests/frames.rs`;
- the length for `npm run sound` (`fframes-sync` now prints it);
- starting the first build before the voice;
- a loudness target and `AudioMixOptions::master_gain_db`;
- `<SCENE>_SHOWN`, so the script shows with its punctuation;
- `<SCENE>_START`, for animation across cuts;
- filtering the QTKit linker warning.

The fixed version was not run again by a fresh agent.

## Open decisions

1. **Raster art.** The reference post's best visuals are images from an image generator (GPT Images). The studio has no image model and uses no paid APIs, so the rebuild draws the thermal figures and pixel icons in code, which looks cruder. Options: keep drawing in code (current default), gradient-map real photos with a shader, or allow a local or paid image generator.
2. **WebGL flag for Remotion.** `ShaderLayer` needs `--gl=angle` for `npx remotion still` and `render`. No npm script passes it yet. Options: set it in `remotion.config.ts` (`Config.setChromiumOpenGlRenderer("angle")`) so every render uses it, or add it only where shaders are used. Default suggestion: the config line.
3. **Loudness.** Both renders measure -22.6 LUFS, well under the -14 LUFS web target. Raising the voice or the master gain is a studio-wide choice, for `npm run voice` or the sound script, and is not part of this spike.
